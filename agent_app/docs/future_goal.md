## System Architecture - Final goal
Research Dashboard (Human Researcher)

→ Stage 1: Research Planning Agent
 - questions, objectives, assumptions, paths

→ Stage 2: Multi-source Retrieval Layer
 - Semantic Scholar
 - arXiv
 - News APIs
 - USPTO Patents
 - Web search
 - papers, articles, citations, evidences

→ Stage 3: Evidence Systhesis Agent
 - Consensus findings
 - Major themes
 - Research trends
 - Evidence base

→ Stage 4: Consensus & Assumption Analysis
 - Dominant assumptions
 - Repeated claims
 - Blind spots
 - Underrep, stakeholders
 - Idea convergence

→ Stage 5: Cognitive Diversity Engine
 - Diversity Lenses: contrarian, historical analogy, cross-disciplinary, failure mode, cultural, economic

→ Stage 6: Human Steering Layer
 - Primary creativity preservation mechanism
 - Research reviews & selects branches to explore further

→ Stage 7: Autonomous Exploration Agent
 - Additional retrieval, synthesis, hypothesis generation

→ Stage 8: Map Generator
 - Interactive graph: consensus ideas, assumptions, alternative branches, evidence

→ Stage 9: Evaluation & Diversity Metrics
 - novelty, diversity, usefulness, assumption challenge, evidence evaluation
