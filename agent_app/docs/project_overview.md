# What Our Agent Does

The Cognitive Diversity Research Agent helps researchers avoid idea homogenization during early-stage research ideation.

Given a research topic, the agent:

1. Generates a conventional LLM-style research response.
2. Detects dominant assumptions and conceptual similarity.
3. Critiques where the ideas are homogeneous or trend-aligned.
4. Generates alternative research directions using divergence mechanisms.
5. Asks a human-in-the-loop question to keep the researcher involved.
6. Evaluates both outputs using novelty, diversity, usefulness, and assumption challenge.
7. Future version: stores high-scoring creative directions and extracts reusable creativity tactics through a memory loop.
